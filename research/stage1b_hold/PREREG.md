# 段階1b: 数字だけで、開示の翌朝に乗って数日〜数週間持つ — 事前宣言

宣言日: 2026-11-02 (下書き)。この文書に OK が出るまで、結果は一切集計しない。OK の後も、候補・期間・基準を後から変えない。

## なぜやるか

段階1 (`research/stage1_numbers/PREREG.md`) では、4つの候補のどれも「始値で入ってその日の引けで手放す」形で不合格だった。
学習期間を見ると、値動きの大半は前日の終値から翌朝の始値までに起きていて、始値の後には残っていなかった。

ただ、業績予想の修正の後は**何日もかけてじわじわ同じ向きに動く**ことが昔から知られている。
1日だけ持つ形ではそれを取りこぼしている。持つ期間を延ばすと取れるかを、数字だけ (LLM なし、費用なし) で確かめる。
ここで取れるなら、段階2で LLM に「本業の好調で、この先も続くか」を読ませる価値が上がる。

## 仮説

予想の修正・来期の予想の伸び・増配の後、翌朝の始値で乗って **5営業日 / 20営業日** 持つと、
その間に同じ向きへ動き続け、コストを払っても残る。

## 段階1から変えないもの

データ、対象 (普通の株・売買の量 0.5億円以上・取引時間外の開示だけ)、4つの物差し (U10・D10・DIV・NXT10) の測り方、
入る日と入れない日 (始値がストップ高・ストップ安)、売りは貸借銘柄だけ、段階1の追記 1〜3 (分割・併合の前後の配当を除く、
値幅制限の印、入る日が同じものをまとめる)。すべて段階1の宣言と同じ。

## 変えるもの: 持つ期間

- **入る**: 段階1と同じ (開示の後の最初の寄り付きの始値)
- **手放す**: 入った日を1日目として、**5営業日目の引け** か **20営業日目の引け** の終値
- 持っている間に上場廃止や売買停止で値段が付かなくなったら、最後に付いた終値で手放したことにする
- 持っている間の分割・併合は、補正の倍率で値段をそろえる

## 候補 (8つ)

4つの物差し × 2つの持つ期間。

| | 5営業日 | 20営業日 |
|---|---|---|
| U10 (上方修正を買う) | U10-5 | U10-20 |
| D10 (下方修正を売る) | D10-5 | D10-20 |
| DIV (増配を買う) | DIV-5 | DIV-20 |
| NXT10 (来期の伸びを買う) | NXT10-5 | NXT10-20 |

5日と20日は「1週間」「1か月」の区切りとして先に置いた。学習期間を見て決めたものではない。

## 成績の付け方

持つ期間が重なるので、**1日ごとに、その日持っているもの全部を同じ金額ずつ持った場合の値動き** を、その日の成績とする
(持っているものが無い日は 0)。

- 1つの売買の、ある1日の値動き: 1日目は 始値 → 終値、2日目以降は 前日の終値 → 終値。どの日も同じ日の TOPIX の同じ区間の動きを差し引く。
  売りは向きを逆にする
- **コスト**: 1往復 0.2% を、入った日のその売買の値動きから引く。報告は 0% / 0.2% / 0.4% の3通り。合否は 0.2% で決める
- **売りの貸株料**: 年 1.10% を、持っている暦の日数分 (週末も含む)。入った日の値動きから引く
- 買いは現物で買う想定なので、金利はかからない
- 年換算シャープレシオ = 1日の平均 ÷ 1日の標準偏差 × √245

## 評価の単位・期間・基準

- **範囲**: ブロックでブートストラップ (1万回)。ブロックの長さは 5日持つ候補は 20営業日、20日持つ候補は 40営業日 (持つ期間の重なりより長くする)。
  8候補分の補正をして **99.375% 範囲**
- **期間**: 学習 2016-11 〜 2021-10 / 検証 2021-11 〜 2024-10 / 金庫 2024-11 〜 2026-10 (段階1と同じ。入った日で分ける。
  金庫は通過した候補だけ、開ける前に再度 OK をもらい、1回だけ)
- **合格**: 段階1と同じ
  1. 学習期間: 1日の平均 > 0 (コスト 0.2% 込み)
  2. **検証期間: 1日の平均の 99.375% 範囲の下限 > 0、かつ年換算シャープレシオが同じ期間の TOPIX 買い持ちを上回る**
  3. 金庫: 1日の平均 > 0、かつ年換算シャープレシオが検証期間の半分以上
- **報告**: 段階1と同じ項目 (1日の平均と範囲、年換算シャープレシオ、回数、1回あたりの平均、勝った割合、年ごと・月ごとの内訳、コスト3通り)。
  加えて、1回あたりの平均を「1日目 (始値 → 終値)」と「2日目以降」に分けて出す (じわじわ動く分がどこにあるかを見る)
- **ランダム対照**: 段階1と同じ (取引時間外の開示がある会社×日から同じ回数を選び、同じ向き・同じ持つ期間で売買)

## 先に書いておく限界 (正直に)

- **検証期間を少し見てしまっている**: 段階1で、同じ4つの物差しの検証期間の1日目 (始値 → 終値) の成績を見ている。
  5日・20日の成績にはその1日目が含まれる。2日目以降は見ていない
- 売りの逆日歩 (売りが多すぎるときに売り手が払う追加の費用) は、データが無いので入れていない。何日も売りを持つと、実際には成績が下がることがある
- 持っている間にストップ安で手放せない日があっても、終値で手放せたことにしている
- 同じ金額ずつ持つので、同時に持つものが多い日 (決算の時期) は1つあたりの金額が小さくなる。実際の資金の割り振りは別に決める
- 修正の後にじわじわ動く現象は昔から知られていて、近年は取り尽くされているかもしれない
- 業績予想の修正から次の決算までに、別の開示 (次の決算や再修正) が挟まることがある。その影響も含めた成績になる
