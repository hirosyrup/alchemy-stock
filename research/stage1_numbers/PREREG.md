# 段階1: 数字だけで、開示の翌朝に乗る — 事前宣言

宣言日: 2026-11-02 (下書き)。この文書に OK が出るまで、結果は一切集計しない。OK の後も、候補・期間・基準を後から変えない。
新しく試したいことが出たら、別の宣言文書を書く。

## 仮説

会社が自分で出す「利益の見通し」や「配当」を引き上げる (引き下げる) と、翌朝の始値で一度反応した後も、その日のうちに同じ向きに動き続ける。
見通しは会社の中の人が一番よく知っている情報で、しかも幅が数字ではっきり出る。
寄り付きの時点で市場が織り込みきれていないなら、始値で乗って、その日の引けで手放すだけで、コストを払っても残る。

判断は開示の後、寄り付きの前に済ませ、寄り付きの成行で入る。始値を見てから入るかを決めることはしない
(始値を見る形、たとえば上限つきの指値で入る形は、別の宣言で扱う)。

LLM は使わない (PLAN.md §11 の段階1)。ここで出た成績が、段階2 で LLM を足したときの比べる相手になる。

## データ

- 開示と数字: J-Quants の財務情報 (`fins/summary`、2016-11〜)。決算短信・業績予想の修正・配当予想の修正の数字が、
  会計基準 (日本基準・IFRS・米国基準) をまたいで同じ項目名で入っている。**開示の時刻つき**。上場廃止した会社の分も入っている (確かめてから使う)
- 株価: J-Quants の日足 (分割の補正前の始値・終値と補正の倍率、売買代金、値幅制限の上限・下限)
- 市場全体: J-Quants の TOPIX の日足
- 銘柄の情報: J-Quants の銘柄の一覧 (日付ごと。市場・業種・貸借の区分)

## 対象 (全候補共通)

- **普通の株だけ**: ETF・REIT・優先出資などは除く (その日の銘柄の一覧で判定)
- **売買の量**: 開示の日より前の20営業日の平均売買代金が 0.5億円以上 (PLAN.md §3 の d)
- **取引時間外の開示だけ**: 開示の時刻が 9:00 より前か、その日の取引の終わり (2024-11-01 までは 15:00、2024-11-05 からは 15:30) 以降のもの。
  取引時間中 (昼休みを含む) の開示は、後回しにする (PLAN.md §4)
- **同じ会社・同じ日の開示は1つにまとめる**: 決算短信と業績予想の修正を同時に出した場合など。下の条件は、まとめた中のどれかで満たせばよい

## 売買の型 (全候補共通)

- **入る**: 開示の後の最初の寄り付き (9:00 より前の開示ならその日、15:00/15:30 以降の開示なら翌営業日) に、始値で入る
- **手放す**: 同じ日の引けに、終値で手放す (1日だけ持つ)
- **入れない日**: 買いで始値が値幅制限の上限 (ストップ高) と同じ日、売りで下限 (ストップ安) と同じ日は、入れなかったとして数えない。始値が付かなかった日も同じ
- **売り**: その日に貸借銘柄 (制度信用で売れる銘柄) だったものだけ。その日のうちに買い戻すので、逆日歩はかからない
- **1回の成績** (実力。市場全体の動きを差し引く):
  - 買い: (終値 ÷ 始値 − 1) − (TOPIX の 終値 ÷ 始値 − 1) − コスト
  - 売り: −(終値 ÷ 始値 − 1) + (TOPIX の 終値 ÷ 始値 − 1) − コスト − 貸株料1日分 (年1.10% ÷ 365)
- **コスト**: 1往復 0.2% (手数料0円、すべり0.2%。PLAN.md §9)。報告は 0% / 0.2% / 0.4% の3通りで並べる。合否は 0.2% で決める

## 予想の修正の測り方

- 測る数字は **営業利益の今期の会社予想**。営業利益の予想が無い会社 (銀行など) は経常利益、それも無ければ純利益の予想を使う
- 「直前の予想」は、同じ会社・同じ会計年度について、その開示より前に出た決算短信か業績予想の修正のうち一番新しいものの予想
- 修正率 = 新しい予想 ÷ 直前の予想 − 1。直前の予想が 0 以下のとき (赤字予想からの修正) は、率が意味を持たないので除く
- 配当は **今期の年間配当の予想** (1株あたり)。直前の予想と比べる。分割で1株の大きさが変わった場合は、補正の倍率でそろえる
- 決算短信で新しい会計年度の予想を初めて出す場合 (通期の決算と同時に来期の予想を出す場合) は、「直前の予想」が無いので修正としては扱わず、
  下の NXT10 で別に扱う
- **来期の予想の伸び (NXT10 用)**: 通期の決算短信の、来期の営業利益の会社予想 ÷ 今期の営業利益の実績 − 1。
  営業利益が無い会社は経常利益、それも無ければ純利益で、予想と実績は同じ利益でそろえる。今期の実績が 0 以下のときは除く

## 候補 (4つだけ)

- **U10 (上方修正を買う)**: 営業利益の今期予想を **+10% 以上** 引き上げた → 買い
- **D10 (下方修正を売る)**: 営業利益の今期予想を **−10% 以下** に引き下げた → 売り (貸借銘柄だけ)
- **DIV (増配を買う)**: 今期の年間配当の予想を **引き上げた** (幅は問わない) → 買い
- **NXT10 (来期の伸びを買う)**: 通期の決算と同時に出した来期の営業利益の予想が、今期の実績より **+10% 以上** → 買い

向きは「始値の後も同じ向きに続く」側だけを見る (逆張りは入れない)。

10% という線は、学習期間を見て決めたものではない (よく使われる区切りを先に置いた)。学習期間で別の線を試すことはしない。

## 評価の単位・期間・基準

- **1日 = 1観測**: その日に入った全部の成績の平均を、その日の成績とする (入ったものが無い日は 0)。
  年換算シャープレシオ = 1日の平均 ÷ 1日の標準偏差 × √245
- **範囲**: 20営業日のブロックでブートストラップ。4候補分の補正をして **98.75% 範囲**
- **期間**: 学習 2016-11 〜 2021-10 / 検証 2021-11 〜 2024-10 / 金庫 2024-11 〜 2026-10 (通過した候補だけ、開ける前に再度 OK をもらい、1回だけ)
- **合格**:
  1. 学習期間: 1日の平均 > 0 (コスト 0.2% 込み)
  2. **検証期間: 1日の平均の 98.75% 範囲の下限 > 0、かつ年換算シャープレシオが同じ期間の TOPIX 買い持ちを上回る**
  3. 金庫: 1日の平均 > 0、かつ年換算シャープレシオが検証期間の半分以上
- **報告**: 1日の平均と範囲、年換算シャープレシオ、回数 (年あたり)、1回あたりの平均、勝った割合、年ごと・月ごとの内訳
  (1〜2か月の大勝ちに支配されていないか)、コスト 0% / 0.2% / 0.4% の3通り
- **ランダム対照**: 同じ期間・同じ対象 (取引時間外の開示がある会社×日) から、同じ回数をランダムに選んで同じように売買した場合と比べる
  (「修正があったこと」ではなく「どの開示でも翌朝は同じように動く」だけではないかを見る)

## 先に書いておく限界 (正直に)

- **業績予想の修正の後の値動きは、昔から知られている現象** (日本株でも研究がある)。知られている分、近年は取り尽くされているかもしれない。
  検証 (2021〜2024) と金庫 (2024〜2026) が直近なのは、それを確かめるのに向いている
- 1日だけ持つ形しか見ない。修正の後に何日もかけてじわじわ動く場合は、ここでは取りこぼす (数日持つ形は別の宣言で)
- 寄り付きのすべり 0.2% は根拠の薄い仮置き (PLAN.md §9)。小さく株価の安い会社では足りないかもしれない
- TOPIX を差し引くのは評価のため。実際に TOPIX を同時に売る費用は入れていない
- 営業利益 → 経常利益 → 純利益の順で使う数字を選ぶので、会社によって測っている利益が違う
- 会社は来期の予想を控えめに出しがちと言われる。NXT10 の +10% は、修正の +10% とは意味が違うかもしれない
- 通期の決算は1年に1回、多くの会社が同じ時期 (5月・2月など) に出すので、NXT10 の売買は特定の時期に固まる
- 売りは貸借銘柄だけで、売り禁 (取引所が売りを一時的に止める) の日も入れてしまっている。実際には売れない日があるかもしれない

## 追記 (成績を見る前に足したもの)

1. **2026-11-02、配当と分割・併合**: 集計の前に件数を確かめたところ、増配と判定したものの約7% (約700件) が、新しい予想がちょうど2倍・3倍・10倍などになっていた。
   分割・併合の前後に、会社が分割前の1株で予想を出し直したり、併合後の1株で先に出したりしていて、「補正の倍率でそろえる」だけでは揃わない。
   そこで、**開示の日の前後1年に分割・併合 (株価の補正の倍率が1でない日) がある会社は、DIV の対象から外す**。
   営業利益は会社全体の金額なので、U10・D10・NXT10 はこの影響を受けない。
2. 値幅制限の判定: J-Quants の日足の UL・LL は値段ではなく「その日にストップ高 (安) を付けたか」の印だった。
   「始値がストップ高と同じ」は「ストップ高の印があり、始値 = 高値」で判定する (売りは「ストップ安の印があり、始値 = 安値」)。意味は同じ。
3. 同じ会社が、引けの後と翌朝の寄り付き前の両方に開示した場合など、入る日が同じになるものは1回の売買にまとめる。
