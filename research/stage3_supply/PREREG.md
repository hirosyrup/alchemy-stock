- 権利付最終日は、月の最後の取引日から数えて 3番目の取引日 (受け渡しが T+2 になった 2019-07-16 以後のルール)
- 対象は普通株 (PRO 市場を除く)。値段が付かない日は、次に付いた値段で入る・出る

## 成績の付け方

- 段階1b と同じ: 1日ごとに、その日持っているもの全部を同じ金額ずつ持った場合の値動き (1306 との差、持っているものが無い日は 0)。
  始値で入る日はその日の始値 → 終値、始値で出る日は前日の終値 → その日の始値で測る (1306 も同じ区間の始値・終値)
- コスト: 売買の往復 0.2% を入った日に引く (報告は 0% / 0.2% / 0.4%、合否は 0.2%)。
  **借りる料金** として、持っている暦日 × 年 3.9% (一般信用の貸株料の水準) ÷ 365 を入った日に引く。逆日歩は過去のデータが無いので入れない (下の「限界」)
- 年換算シャープレシオ = 1日の平均 ÷ 1日の標準偏差 × √245

## 評価の単位・期間・基準

- **範囲**: 40営業日のブロックでブートストラップ (1万回)、4候補分の補正 (ボンフェローニ) をして **98.75% 範囲**
- **期間** (入った日で分ける): 学習 2016-11 〜 2021-10 / **検証 2021-11 〜 2024-10** / 金庫 2024-11 〜 2026-10
  - S16 は日足の金庫の前半 (2024-11 〜 2025-10) をすでに開けてしまった (私の誤り)。S16 の金庫は **2025-11 〜 2026-10 だけ** で見る
  - 金庫は検証を通った候補だけ、開ける前に再度 OK をもらい、1回だけ
- **合格** (段階1b と同じ):
  1. 学習期間: 1日の平均 > 0 (コスト込み)
  2. **検証期間: 1日の平均の 98.75% 範囲の下限 > 0、かつ年換算シャープレシオが同じ期間の TOPIX 買い持ちを上回る**
  3. 金庫: 1日の平均 > 0、かつ年換算シャープレシオが検証期間の半分以上
- **報告** (合否には使わない): 1日の平均と範囲、年換算シャープレシオ、回数/年、1回あたりの平均・中央・勝ち、コスト3通り、年ごとの内訳、
  発表の時点の貸借銘柄 / それ以外 で分けた結果 (S16・S18・S33)、売買代金の大きさ別、
  逆日歩が 1日いくらまでなら残るか (損益の分かれ目)、一番悪い 5件と一番悪い月、4つを重ねた場合の成績 (同じ金額ずつ)
- **ランダム対照**: 同じ日に、同じ数の銘柄を対象全体 (その日に値段が付く普通株、前の 20日の平均の売買代金が同じ 1/5 の帯) から無作為に選び、同じ持ち方で空売りする (1,000回)。
  候補がランダムの 95% 点を上回るかを報告する

## 先に書いておく限界 (正直に)

- **学習期間は全部探索で見ている**。候補の線 (+5%・5倍・5日・4日・貸借だけ など) もそこで決めた。学習期間の合否は形だけで、本当の確かめは検証期間
- **空売りできたかは確かめられない**。制度信用で売れるのは貸借銘柄だけ。S16・S33 の効きの多くは貸借でない銘柄 (一般信用の在庫があるときだけ売れる) から来ていた。
  一般信用の在庫と逆日歩の過去のデータは無い。ここで通っても、実際に売れるかは、注文を出さずに記録する期間 (kabu の API で売建の可否・プレミアム料・日証金の規制を記録) で確かめる
- S17 を貸借銘柄だけにしたのは、学習期間で貸借でない銘柄が −0.14% と効かなかったのを見て決めた
- 2022-04 の市場の再編で、分売の目的 (1部への昇格のための株主づくり) が変わった。件数は 年 約100件 → 55〜75件に減っている。形が変わっている可能性がある
- S33 は 1銘柄の踏み上げで大きく負けることがある (学習期間で 5日で −105%)。同じ金額ずつ持つので、持つ銘柄が少ない日に効く
- 優待 (S18) は同じ日に何十社も重なる。1日の成績は「その月のかご」1つでほぼ決まり、件数ほど独立ではない
- 1306 との差で測るので、相場全体の上げ下げは取らない。1306 を買う分の手間とコスト (売買・信託報酬) は入れていない
- 学習期間の探索では TOPIX (指数) との差で測った。指数の 9:00 の始値は、まだ寄っていない銘柄の前日の値段を含んで実際より動かない。ここでは実際に売買できる 1306 で測るので、探索の数字と少しずれる
