## 分かってきたこと (候補を考えるときの前提)

- TDnet の開示にみんなと同時に乗る形は、数字の知らせは2〜3秒、文章の知らせも5〜10秒で値段に入る。引け後の開示は翌朝の始値に入りきる
- LLM の読み (向き・動くかどうか) は当たっている。勝ち目は「みんなより先に読める公開情報」か「みんなが売買できない時間 (夜間)」にありそう
- 見つかった候補はどれも年に数件〜数十件で細い。情報源ごとに重ねて件数を増やす方針 (HANDOFF.md の 2026-11-03 追記)
- 需給・人のくせの候補 (16・17・18・23・33) はどれも空売り。全体では強いが、効きの多くは貸借でない小さめの銘柄から来るものが多い (16・23・33)。
  決め手は「その時点で空売りできたか」。日証金の申込停止は過去の記録がある (J-Quants の margin-alert、分売の貸借銘柄では 3%) が、一般信用の在庫と逆日歩の過去の一覧は無い。17・18 は貸借銘柄だけでも残る
- 16・17・18 はほかの候補とほとんど重ならない。23 と 33 はほぼ同じ現象 (重なり 56%、月の相関 +0.52)
- ロジックができてきたら、注文を出さずに「出していたらどうなったか」と「その時点で空売りできたか (kabu の API の一般信用売建フラグ・日証金の規制・プレミアム料)」を
  候補が出るたびに全件記録する期間を置く (ユーザーと合意、2026-11-04)。空売りできた組とできなかった組の値動きを比べ、過去の成績とのずれを確かめる。kabu の API には口座が要る

## 資金の回し方の案 (2026-11-05、ユーザーと話した内容)

前提: 売買は IBKR だけ (空売りは IBKR で借りられる 581銘柄だけ、ほぼできない前提)。元手は 50万円から。日本株は 100株単位なので 1回 10万円前後になり、同時に持てるのは数件。

- **作戦ごとのお金の使い方の違い**
  - 11 (題名で判断して買う): 秒の勝負。30分で手放す。年に約40件。**売ってからお金を回す余裕は無い**
  - 41 (分売の後の戻り)・12・15 (夜間 PTS): 前の晩や数時間前に分かる。数日〜1週間、または翌朝まで
  - 42 (自社株買いの期間): 約2か月持つ。効きは毎日少しずつ積み上がる (1日 +4bp ほど) ので、途中で売っても失うのは売り買いのコストだけ
- **案: 自社株買いを「空いているお金の置き場所」にする**
  - 空いているお金は、自社株買いの「買いの圧力」の点数が高い銘柄に置く (すぐ売れるよう売買代金 1億円以上に限る)
  - 41・PTS など前もって分かる出来事が来たら、点数の一番低い銘柄を売ってお金を回し、終わったら戻す (入れ替えのコストを見込む)
  - 11 の分は、(a) いつも 10〜20万円を空けておくか、(b) IBKR の信用の買う余力を使う (30分だけ借りる。IBSJ の日本株の信用買いの決まりは未確認)
- **自社株買いの絞り方** (同時に数件しか持てないので必須): 毎日、買っている期間の銘柄に「残りの金額 ÷ 残りの日数 ÷ ふだんの売買代金」の点数を付け、
  5つの組に分けて点数が高いほど成績が良い段々の形になるかを、成績を見る前に決めた式で確かめる。上位数件だけで線を探さない (件数が少なく、たまたまと見分けられない)。
  最後は日足の検証期間 (2021-11〜2024-10、自社株買いはまだ見ていない) で宣言してから1回だけ
- **始め方**: 最初は作戦を 1〜2つに絞り、資金の回し方は単純に (例: 空けておいたお金で 11 と、41 だけ)。慣れてから置き場所の作戦 (42) を足す
